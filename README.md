# Rs3xOsrs Resource Pack for HDOS

![icon](https://i.imgur.com/dkiXMCt.png)

## Description
I did not create this theme, I simply modified it to work with HDOS. 

The original theme for RuneLite can be found here: https://github.com/melkypie/resource-packs/tree/pack-Rs3xOsrs

This pack by default uses the hitsplats that were introduced with the Constitution update. They can be disabled in the ui-themes plugin settings or by removing the hitsplats folder from the /hdos folder within the pack.

## Tools

#### Tools used during the creation of this pack
* [GIMP](https://www.gimp.org/) - Image processing tool.
* [Imagemagick](https://github.com/ImageMagick/ImageMagick) - Bulk image processing tool and resizing with CubicSpline algorithm.
* [Optipng](http://optipng.sourceforge.net/) - Lossless PNG compression.
* [paint.NET](https://www.getpaint.net/) - Image processing tool.
